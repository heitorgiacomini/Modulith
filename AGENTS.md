# Repository agent instructions

## Planning

- Save every finalized Plan Mode plan under `.github/plan/`.
- Use a descriptive kebab-case filename ending in `-plan.md`.
- Save the decision-complete plan, not the raw user request.
- Update the existing plan file when revising the same plan instead of creating duplicates.
- Never overwrite an unrelated plan.
- If the active Plan Mode prohibits file writes, preserve the exact plan in the response and make saving it the first action when execution begins.
